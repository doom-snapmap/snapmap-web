# Privacy Policy

Snapmap+ runs no analytics, telemetry or tracking. It contacts the mod store only for what you do: publishing a map that uses mods uploads those mods, and playing such a map downloads them. While you play a published map that uses mods, your game may also tell the store, anonymously, the name of a mod file that map's mods lacked; nothing about you is sent.

Apart from the mod store above, the only time anything leaves your computer is when **you** click **Send** in the feedback or crash-report
dialog. When you do:

- **What's sent:** the category, title, and details you typed, plus the Snapmap+ version and your game's identity (the DOOM build, the renderer and the start of the executable's fingerprint) — and, for a crash
  report only if you leave the box checked, recent log text with your Windows account name and machine name
  stripped out first.
- **Optional:** a contact handle (email / Discord / GitHub), only if you choose to add one so we can reply.
- **Where it goes:** to Snapmap+'s feedback relay, which files it as a **public** issue on the project's
  GitHub tracker. Anything you type can be seen publicly — don't include anything sensitive.
- **Not collected:** no account and no tracking on our side. The mod store keeps request counters under one-way digests of your network address and, when you publish, of your publishing key, and remembers the SnapMap account name that key presented so no other key can take it; it never keeps the address itself. No personal data beyond what you
  optionally type.

Your maps, prefabs and settings leave your computer only when you publish, export or send them yourself; publishing a map uploads the mods it uses, which includes the My overrides mod if the map uses it.
